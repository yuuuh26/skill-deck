# Skill Deck

複数AIで使う自作Skillを管理する個人用PWA。GitHub Pagesの `/skill-deck/` で動作します。

- Skillの作成・検索・本文コピー、版ごとのAI対応状況と必要ツール
- 保存ごとに旧版を維持。過去版を元に新しい最新版を作成
- 編集中の本文Undo / Redo
- IndexedDBへの端末内保存、JSONの完全バックアップと検証付き復元・統合
- 閲覧用Markdown出力、オフライン利用、永続ストレージ状態の確認

## 使い始める

リポジトリの `main` ブランチのルートをGitHub Pagesとして公開してください。外部ライブラリやビルド処理は不要です。HTTPSのGitHub Pagesから開くとコピー、PWA、サービスワーカーを利用できます。

端末内のIndexedDBデータはブラウザ削除や機種変更で失われる可能性があります。設定画面から定期的にJSONをエクスポートしてください。インポート前にはファイル内容・ID参照・件数を検証します。置き換え操作は明示確認後、ひとつのIndexedDBトランザクションで実行します。

秘密情報はSkill本文に保存しないでください。`noindex`はアクセス制限ではありません。

## 開発検証

`node --test tests/*.test.mjs` でバックアップ検証のテストを実行できます。
